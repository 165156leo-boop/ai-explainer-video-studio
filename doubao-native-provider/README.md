# 豆包本机后台

这是 AI 科普动画生产工作台的 Electron 伴随服务。它使用用户主动登录的豆包网页版会话完成图片和视频任务，并把生成文件回传到工作台的候选区。

核心约束：

- 每个豆包账号使用独立的持久化会话；同一账号最多并发 2 个图片任务，第 3 个排队，视频任务串行；不同账号可以同时工作。
- 每条生成任务使用共享该账号会话的独立屏外 Electron 页面；只有首次登录、会话失效或人工验证时显示对应账号窗口。
- 只监听 `127.0.0.1`，只读取工作台创建的参考图目录，不向外暴露 Cookie。
- 提交结果不确定时停止并要求人工核对，不自动重复发送。
- 优先使用豆包响应明确提供的图片 `image_ori_raw` 和视频原始下载地址；不通过裁剪、拼接或 AI 修补修改画面，也不绕过登录验证或会员限制。

实现参考了 [Doubao Studio](https://github.com/dorakoo/doubao-studio) 的多账号持久化分区、后台页面常驻和任务安全恢复思路；本目录是面向本工作台契约重新编写的独立实现，没有引入其 UI、项目管理、CSV、MCP 或大体量自动化代码。

媒体字段和豆包视频 `qAAB` 地址协议参考了 MIT 许可的 [ihmily/doubao-nomark](https://github.com/ihmily/doubao-nomark)，本项目按现有 Electron Provider 契约重新实现：图片在实时生成响应中精确选择 `image_ori_raw`；视频优先从“我的创作”的下载信息取得 `main_url`，受信任的 `fallback_api` 仅作回退。
